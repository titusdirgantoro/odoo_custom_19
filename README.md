# 🧩 Custom Odoo 19 Modules

Repository ini berisi kumpulan **modul kustom** yang dikembangkan untuk sistem **Odoo 19**, mencakup berbagai penyesuaian dan integrasi khusus kebutuhan bisnis internal.

---

## 🚀 Instalasi

### 1. Clone repository
Masuk ke folder addons kustom milik Odoo 19 (misal: `/opt/odoo19/custom_addons`) dan clone tanpa membuat folder baru:

```bash
cd /opt/odoo19/custom_addons
git clone https://github.com/titusdirgantoro/odoo19-custom-modules.git .
